# Commands

| Command | Description |
|---|---|
| `nemoclaw onboard` | Create a sandbox with the onboarding wizard |
| `nemoclaw list` | List sandboxes |
| `nemoclaw <sandbox> connect` | Open a shell in the sandbox |
| `nemoclaw <sandbox> status` | Show sandbox state |
| `nemoclaw <sandbox> destroy` | Delete the sandbox |
